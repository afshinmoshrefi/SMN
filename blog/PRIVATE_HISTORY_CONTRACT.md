# Private inclusive history derivation

`derive_history_panel(ohlc, session_manifest, *, instrument, anchor_date, days, as_of, dataset_sha256, source_ref, requested_years=40)` is a pure function. It performs no fetching, configuration imports or publication. Inputs are a specific adjusted series, OHLC rows and an independently generated reviewed session calendar. The default forty annual calendar years provide the annual history needed to compare ten four-year-cycle observations with their complementary years; it does not optimize the lookback.

The first session inside the inclusive start/end interval supplies the adjusted **closing** entry price. The last session inside that interval supplies the closing exit price. The end is start plus calendar days minus one. Neither endpoint advances beyond that end. A missing expected session holds the data; a holiday is handled by the supplied calendar, not treated as a missing quote.

MFE/MAE use subsequent sessions' highs/lows through exit, excluding entry day's already elapsed intraday range. The actual entry return of zero is included as the excursion boundary. One-session windows have zero close-to-same-close return and zero observed post-entry excursion. These are provider-adjusted series changes before costs, not certified dividend-inclusive investor returns. Extrema do not establish an intraperiod path or timing.

`session_manifest` requires `calendar_id`, `start_date`, `end_date`, ordered unique ISO `sessions`, `expected_latest_date`, and `source_ref`. The private US exchange scope rejects a latest boundary older than a known session before today's UTC date. A latest session on today's date additionally requires `expected_latest_close`, an aware timestamp already reached at audit time. The adapter independently supplies the exchange holidays and close times; this module cannot authenticate a calendar merely from its asserted ID or hash. The real review adapter uses exchange_calendars 4.13.2 XNYS, with full generated session records, version and input dates saved.

The dataset hash identifies the upstream source bytes; the separately computed normalized OHLC hash binds the rows actually parsed. They are audit links, not signatures or source authentication. Full instrument identity is required. Market semantics and eligibility still pass through `market_policy` separately.

Outputs contain percent-only `observations`, actual `windows`, declared `coverage`, `history` quality fields, `issues`, `status`, and provenance hashes. Every output is private and unpublishable. A held result may expose valid subsets for diagnostics but must never be used as a passed history gate. Windows entirely before the supplied dataset are labeled `source_data_unavailable`; this does not assert provider or instrument inception. Internal gaps, invalid/nonpositive OHLC, unexpected sessions, duplicate dates, stale/future data, malformed calendars, and unrepresentable arithmetic hold. No missing value is replaced with a zero.

For retrospective examples, `as_of` and `audited_at` are the actual current audit clock while the seasonal anchor remains the original historical article date. Cohort completion uses the earlier of these dates. This is a fresh calculation on a present adjusted snapshot, not point-in-time reconstruction. Older cached ChartData4 rows that exit after the displayed inclusive end remain unverified for the corrected article contract.

Raw ChartData4 all-zero rows with missing/zero entry/exit prices are separately held by `cohort_policy` as ambiguous historical placeholders. Genuine normalized all-zero observations from verified completed OHLC windows remain valid flats.
